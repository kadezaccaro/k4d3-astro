## Project Overview

The goal was to build a home server that serves as both a learning environment and a platform for self-hosting various apps. This lab will assist in my journey as I learn more about ethical hacking, sys admin, and more.

## Lab Architecture

I wanted to create a more real-world IT environment&mdash;not simply a few virtual machines (like a Kali attacker and a victim machine).

To isolate the hacking lab from my main network, I virtualized pfSense, serving as a nested firewall/router for the lab. I also configured VLANs to segment various systems from each other.

## Implementation

### Hardware

I installed Proxmox hypervisor on a power-efficient mini PC. To run more VMs simultaneously, I upgraded the system with a second memory chip (32GB total) and a second SSD for more storage and backups. I hope to set up network-attached storage (NAS) eventually, however.

### pfSense Firewall (Virtualized)

While I prefer and use OPNsense for my main network, I chose pfSense for this lab to gain experience using both.

I segmented the machines into VLANs and established firewall rules to control communication between them. I'm currently allowing the Attack VLAN access to the vulnerable device VLANs as well as the Internet:
