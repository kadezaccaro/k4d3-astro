## Network Topology

The main goal was to expand my learning with a hands-on project to compliment my computer networking class studies. The plan was to replace my ISP's all-in-one with a mini PC running OPNsense as a router/firewall.

The security features of my ISP was very limited: no WPA3, no VLANs for segmentation, and not even a separate guest network.

I chose OPNsense over pfSense because the organization/UI feels much more intuitive to me, though, I did end up virtualizing pfSense in my home lab to gain experience using both.

In addition to the OPNsense box, my infrastructure includes a managed switch to offer more ports since my box only has 2 ports, wireless access point (one that is VLAN capable), and another mini PC server for homelabbing.
